# 智用力评分规则手册

版本：1.6　｜　规则日期：2026-11-09

本手册为当前规则入口。评审模型按固定判据，结合相关对话上下文判断本人的AI使用表现；程序负责来源整理、合同检查与精确算分。历史报告继续使用其原规则，不因手册更新自动重评或升级。

2026-11-09最新范围决定：恢复工作日方案，正常周周五24:00截止计分、周六02:00封口评审、周一08:00前准备好候选，非工作日行为仅作背景，仍由管理员确认发布。**当前代码已接入工作日范围版本、日常准备与自动调度，并通过本地合成/数据库检查；完整真实周/月与百人运行仍未验收，不得把旧自然周结果改称工作日周评。** 周/月仍以日历期间为键，计分只纳入冻结的实际工作日；来源须覆盖封口水位，截止后的新行为不倒填。法定日历缺年份则暂停，整周休假不生成员工周分。分项、分值、不设数量门槛及月至少3周政策不变。目标范围与实现缺口见[73号决定](../research/ai-usage-assessment/73-workday-scale-restoration-20261109.md)。

## 一、评什么

智用力每周出评分，每月出评分与评级。评价以当时实际需要、有效要求、本人职责和可核对行为为依据。

| 维度 | 权重 | 评价内容 |
| --- | ---: | --- |
| P 提示词质量 | 20% | 目标、信息和约束是否清楚、充分、适用 |
| M 任务驾驭度 | 35% | 方法分工、依赖推进和执行调整是否合理有效 |
| J 判断核验 | 30% | 判断依据、核验安排和结果处理是否准确相称 |
| E 使用效率 | 15% | 交互组织、失效止损和实际复用是否合理有效 |

成果质量单列，不计入PMJE总分。任务复杂度、工具量、调用量、文字长度、价格与Token不直接加减分；AI自主执行的成绩不能直接归为本人贡献。简单目标、成熟流程及委托AI设计方法，均按实际表现评价。

## 二、怎样阅读对话、识别目标

目标是结合当时有效上下文，用户希望AI帮助获得的答案、判断、改变或成果。能够确定对象或问题以及当前期望结果即可；查询、解释、学习可以成立，不要求预先写出方法、验证方案和最终成果。

先还原相关对话过程中的目标、阶段、有效要求、可用材料和本人职责。历史、附件、模板、Skill和用户的明确采纳均可构成有效上下文。短句可承接前文，不因未重复已知信息扣分；后续新增要求也不能倒填为早先缺陷。

同一目标的追问、纠错、实施、测试和交付保留为连续过程；独立目标按语义拆分，不按消息或请求数量拆分。同一会话可有多个目标，同一目标也可能跨会话，但跨会话关联须有对象、意图和反馈关系的依据。

无法确定完整父目标时保留本人片段、候选目标和边界状态，区分表达不清、正常探索、目标演化、缺前文、截断和归属未知；可独立判断的局部输入仍进入评审。纯寒暄单列保留，不虚构目标。目标难识别、多次追问或同会话多个目标，本身不自动扣分；有本人可控的必要表达缺口、要求混淆或无效往返及具体影响时，才按适用项判断。

任务识别用于组织上下文和证据。**不设识别出几个任务才能评分的门槛，也不按完成目标数量、好坏目标占比决定得分。** 方法、验证和成果不是目标成立的前提；有实际适用机会时，按M、J等对应项的质量判据评价，不另设统一奖励。

某次回复被截断，只限制该次已保存回复的使用，不使完整用户输入及后续轮次作废。某次请求本身被截断，只能分析已保存部分；历史截断不能定位时如实保留未知。会话标识能够关联来源，不证明原文全部完整或所有内容均为本人创作。

## 三、模型怎样形成判断

评分对象是本周12个分项的整体表现，阅读依据是相关目标的过程。模型先核对支持、反证、阶段变化、恢复和残余问题，再对每项给出一次表现判断。理由须说明当时需要、本人行为、质量优势或不足、作用依据及适用范围，解释为何属于这一档、为何不是相邻档。

综合判断关注事实的相关性、作用及影响范围，不能用“综合考虑”代替具体解释。展示的代表原句用于定位依据，还需交代会改变结论的其他事实及限制。普通请求多不会按数量稀释已证优势，最好一例也不能掩盖其他未处理必要缺口；局部高分不能直接推出整周高分。

**不按多数票、不平均任务分、不计算好坏占比，不为案例逐一新增加扣分公式或频次门槛。** 模型有语义判断空间，但须遵守固定分项判据、档位、归属和证据边界。证据不足以判断全期时，保留范围或未决，不能假装完整。

| 分数 | 表现档 | 判定条件 |
| ---: | --- | --- |
| 100 | 卓越 | 相对90，本项准确性、相称完整性、有效性或简洁可靠性具有突出的可核质量 |
| 90 | 出色 | 相对80，有充分本项正证，可具体核对做法与关键要求、条件或作用的关系 |
| 80 | 针对性良好 | 做法贴合具体条件，有可明确指出的质量优势 |
| 70 | 合理有效 | 有正面事实支持做法相称，足以推进当前工作 |
| 60 | 实质非关键不足 | 本人可归责的实质非关键不足未妥处，存在具体影响 |
| 40 | 必要缺口 | 本人可归责的必要控制缺失，具体影响仍未处理 |
| 20 | 严重失效 | 本人可归责的必要控制严重失效，具体影响明确 |
| 0 | 关键越界 | 本人知情、可控的关键越界造成实际影响 |

70是正向表现。高档要说明更强的质量依据，不能只更换形容词；完整、未见问题、持续纠错和AI赞同不直接构成卓越。缺少高档证据也不等于存在缺陷。简单工作和正确采纳可达到高档，不要求先出错、创造新方法或增加无关工作。

负向判断须有当时可知、本人可控、可行替代及具体影响的依据。合理探索、AI错误、外部阻塞和材料缺失不直接成为本人不足。充分恢复后不永久罚，残余损失或风险继续评价；仍未处理的必要缺口不能被其他优点抵消。

## 四、12个分项的固定判据

以下明确每项评价对象，模型结合实际上下文和上述档位判断，不把固定案例或某位员工的历史分数当作标准答案。

| 分项 | 评价对象 | 判断重点 |
| --- | --- | --- |
| P1 目标清楚 | 当前希望获得什么 | 目标、阶段和期望结果是否足以定位，必要细化是否准确相称 |
| P2 信息充分 | 提供了什么信息 | 所需事实、来源与材料是否可用、适配，适用范围和限制是否清楚 |
| P3 要求约束 | 有效要求与边界 | 要求是否具体、相容、可执行，保留条件和可接受结果是否准确 |
| M1 方法分工 | 如何安排人与AI的工作 | 方法、职责、交接是否贴合条件，既有流程和委托AI想方法均可合理 |
| M2 依赖推进 | 如何处理推进条件 | 必要前提、依赖和阶段衔接是否相称处理，不强求每个任务都有复杂依赖 |
| M3 调整执行 | 如何响应实际反馈 | 调整是否依据有效反馈，范围与时机是否合适，必要控制是否保留 |
| J1 判断依据 | 判断为什么成立 | 本人的解释、比较、取舍是否有实际依据，事实、假设与限制是否分清 |
| J2 核验安排 | 如何辨别是否满足要求 | 检查设计是否针对关键要求、有判别力，不能把计划核验当已执行 |
| J3 结果处理 | 如何采用、修正或拒绝结果 | 处理是否基于适当依据，采用范围是否相称；正确接受好结果也可高分 |
| E1 交互组织 | 如何组织有效往返 | 信息和指令是否便于推进，避免可归责的无效往返，不按轮数直接判断 |
| E2 失效止损 | 如何处理无效路径 | 发现、停止或改变失效路径是否及时相称；必要探索和正常重试不自动算浪费 |
| E3 复用自动化 | 如何实际复用有效资产 | 既有材料、流程和自动化的选用是否适配、有实际作用，不按资产数量给分 |

证据要求与评价对象相称。P可由当时输入和背景的具体对应支持，不追加后续软件实测门槛；J2可由设计判别力支持，但不能声称核验已经执行。方法建议、实际选择、实施、验证、满意、采用及业务效果分别说明，不能相互替代。

## 五、状态、归属与重复计分

- 无处理机会、不适用、不可观察、归属不明、待复核和证据不足与表现分开，不补0分、均值或满分。某次系统执行失败、评审失败与目标整体失败分别记录，须结合后续恢复和交付判断，不能直接判为用户低分。
- 历史、附件、模板、Skill和工作流均计入当时有效上下文。用户选择和调整流程按本人实际行为评价，AI自主执行不直接记为用户贡献。
- 同一行为主张在P/M/J/E中确定一个主要评分归属；一句话包含不同主张时，分别说明各自依据，不因文字相同合并，也不重复奖励同一作用。
- 来源数量不用于加分、扣分或调整个人权重。结果保留本维已评分子项数、实际依据及未决事项。

## 六、怎样形成周分和月分

### 周评分

周期为北京时间周一00:00至下周一00:00，结束时刻不计入本周。对12个分项分别综合本周支持、反证、恢复及未决，形成每项一次判断；不平均任务分，不按多数票或最佳单例决定整周表现。

普通行为数量不稀释有据优势，最佳一例不掩盖其他未处理不足。局部高分不直接推出整周高分。

### 正式出分所需观察

| 范围 | 最低参与条件 | 有效性条件 |
| --- | --- | --- |
| 完整工作周（以日历周为周期键） | 不设任务数量、活跃日期或每维固定依据条数门槛 | 来源已处理完成，PMJE均有可评本人依据，没有关键归属或判断未决 |
| 自然月 | 至少3个正式周评分 | 采用同版完整周评，月内来源及必要缺口处置已核完，PMJE均可评 |

一项独立目标可能含多次对话，也可能在一次对话中出现多个目标。任务数量只作来源组织与覆盖描述，不作为评分资格或加减分依据。不按请求数、消息数或人为拆分凑任务；一个目标也可以形成周评分，前提是四维确有可评本人依据、来源处置完成且没有关键未决。资料少只解释为当前可观察范围有限，不推断长期稳定能力。

月只有0、1、2个正式周评时保留分析，不出月总分和评级；至少3周才出。缺周不补零、不额外扣分，也不降低其他有效周的分值。低分周同样计入资格，不能因为分数低而排除。月评至少3个有效周是沿用的产品政策，本版保留1.5取消任务数门槛的决定，不代表已完成测量精度或独立人评校准。

来源未完成显示“数据或评测待完成”，不能当作员工没使用。关键归属争议、待复核和来源缺失不能靠删除某周绕过。报告保留实际有效周数，旧报告按旧规则重放。

### 月评分

周期为北京时间每月1日00:00至下月1日00:00，结束时刻不计入本月。以自然周与月份的交集划分评价期间；各期间使用同一023评分尺。仅纳入具有正式周评分的期间，每个分项按其可评期间在月内覆盖的日历天数加权，再计算四维分数、月总分与评级。月末不再次由AI自由判档。

月分不平均四个周总分，不按周分取最高、按请求次数加权或多数票。日历天数是评价时段权重，不是活跃天数加分。跨月周按月内片段单独评价；月外历史只作背景，月末之后发生的材料不回填本月。重复引用的同一事实只计一份支持。

首尾不足周标明实际覆盖日期，不冒称完整自然周。该片段只有在对应完整周已有正式周评分时才计入月分；月外行为不进入本月评分。没有完整周材料时不得用月内片段凑足3周。缺周、来源未完成与本人无处理机会分开显示；来源与期间处置未完成、用于计分的证据未核对时，不发布月度数值。来源已封口且各期间状态已核对，但部分分项实际不可观察或归属未决时，可保留已核可评范围的数值，未知部分不补数，正式综合分与月级还须满足观察资格及第七节的资料条件。已证必要缺口须在月末逐项确认“仍未处理”或“已恢复”，并绑定实际依据；仍未处理时，本维采用相应最低缺口分。恢复保留发生时间，不改写旧周结果。

### 分数计算

1. 维内：没有未处理必要缺口时，当前已有数值判断的独立子项等权平均。若存在40、20或0分对应的已证未处理必要缺口，该维取这些缺口中的最低分，不用其他优点平均抵消。
2. 总分：`S = P × 20% + M × 35% + J × 30% + E × 15%`。
3. 四维均有数值才生成总分。任一整维没有数值，不补分、不向其他维度分配权重。某维部分子项无数值时，保留可评部分并显示分母。
4. 使用精确数值计算，页面按四舍五入保留一位小数；评级依据未舍入总分。

效率E固定占15%。按均值计算时，本维有k个数值子项，在有效分值范围内，单项增加10分对总分影响为`1.5/k`分；必要缺口优先时按实际公式重新计算。页面展示实际依据、评分内容、数值子项数及敏感性，不按来源少降低分数，也不将单一来源外推为稳定效率。

## 七、月度评级

| 等级 | 未舍入月总分 |
| --- | --- |
| L5 | 90 ≤ S ≤ 100 |
| L4 | 80 ≤ S < 90 |
| L3 | 70 ≤ S < 80 |
| L2 | 60 ≤ S < 70 |
| L1 | 0 ≤ S < 60 |

满足观察资格后，等级按未舍入月总分确定；不按任务数量、使用日期增加或减少分数，不附加复杂任务数量或单维最低分。没有完整总分时不生成等级，按真实原因显示状态。周报不发布月度等级。

资料提示逐条核对并保留：某一期间局部不可观察，而同一分项已有其他可评期间、整月观察资格充分时，未知部分不补数、不计入该项分母，保留月分及等级并说明限制。用于计分的关键归属争议、待复核、来源覆盖未完成、必要缺口月末处置未核及整维无数值仍阻断；不能将这些问题改标为资料限制绕过。旧1.1至1.5结果按原合同保留。1.6收敛上下文评审原则，沿用1.5资格、025月汇总、023分档、PMJE权重和必要缺口优先。

若未舍入总分为89.99，显示90.0分，等级仍为L4；页面同时标明未舍入值与等级。等级解释本期已评分范围内的AI使用表现，不作个人长期能力认证。

## 八、用户怎样核对依据

报告按“分项分数 → 判定理由 → 对应原文 → 来源时间与上下文”展示。用户查看本人报告及获准展示的依据，管理员查看全员结果并评审、发布。

每份报告绑定评分规则版本。重新评审形成新修订，保留原结果与修订记录；旧版结果不静默覆盖。查看历史报告时，打开该报告实际采用的规则。

AI Hub已有记录是材料来源；未记录的本地操作和线下成果不补造。结果明确保留来源缺口、归属状态和已验证范围。


## 九、当前执行流程与版本

1. 整理本期来源：按实际会话和请求标识关联，核对角色、本人输入、反馈、截断与来源缺口，保留出处。
2. 结合对话识别目标及连续过程：每条本人输入进入目标或非任务处置，边界未知和可独立评片段保留，不因难识别删除。
3. 按固定判据进行上下文评审：本地可由当前Codex直接判断，按需补读关键上下文，输出12项判断、理由、支持及限制。用户已于2026-11-10明确授权公司AI Hub `deepseek-v4.1-flash-local`专用接入，为完成全员AI使用评分流程自行调用所需模型请求，无需逐批申请次数；仍记录实际用量、执行预算、失败和未知结果。后台评审显式启用，采用同一固定判据，生产变更与员工结果发布边界不变。接入成功不等于评分语义或全量流程已经验收。
4. 程序校验来源、归属、引文、时点、集合、资格及精确算术；关键未决保留，不能由结构通过自动宣称语义正确。
5. 周形成12项综合判断，月复用同版已核期间确定性汇总；报告绑定实际规则和语义合同，旧结果须按新合同实际复核后才能形成新修订。
6. 核对后发布报告，用户可回溯原文、上下文与限制。本地验证不等于生产发布或独立人评校准。
