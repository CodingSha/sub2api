# sub2api 0.2.25 定制版升级记录

## 来源与范围

本次在 `feature-zhiyongli` 合入上游 `Wei-Shaw/sub2api` 的 `v0.2.25`（`348997267`），升级前源码为 `debd37b8e`。保留 APSAT 内容审计、白名单、智用力管理和个人报告、WorkBuddy 使用配置及已有部署方式。前后端、网关与数据库迁移随上游升级；智用力评分算法、Worker 和已发布评分不在本次变更范围。

页面内置更新下载的是上游发行二进制，不能用于本定制版升级。本次从已提交并推送的源码构建自有镜像，明确传入版本与完整提交号；不通过页面更新。

## 合并处理

- 保留审计服务依赖注入、白名单协调器和各协议响应采集，同时接入上游 Gemini 缓存、MCP 和请求字段歧义检查。
- 路由维持认证、模型白名单、字段检查、审计采集和业务处理的顺序；上游路由回归适配本地审计参数。
- 保留 OpenAI 分组默认 WorkBuddy 页签，Codex 模式沿用上游 API Key 默认值；测试通过真实页签选择进入相应配置。
- 回归发现普通 Anthropic 流式入口的终态收尾和正文采集在原源码基线中缺失，透传入口会在终态标题行过早结束。补齐完整终态帧转发、正文采集与及时关闭，并保留上游流大小限制和用量计费；重复终态不再重复转发。
- 构建工具链升级到 Go 1.27.4。上游标签内 VERSION 尚为 0.2.24，本分支明确记录 0.2.25。

## 发布门槛与回退

生产发布证据保存在主机私有目录 `/data/zhiyongli/releases/upstream-0.2.25-20261126/`。原配置、容器信息、数据库完整备份及角色备份仅在主机保存，不入 Git。

发布前需验证前端构建、关键前端及 Go 回归、旧迁移校验和、新迁移在隔离结构库执行、生产备份完整性及新镜像版本。生产单实例替换存在短暂不可用与在途请求中断风险，不能称零中断。

切换仅替换应用镜像，沿用现网参数、挂载、网络和端口，保留 PostgreSQL、Redis 与 Worker；健康检查失败恢复原配置和镜像。新增数据库结构不通过整库恢复回退，避免覆盖升级后新请求；数据库回退须另行评估。

发布后核对应用版本和提交、静态资源、管理员及个人智用力页面、网关用量及审计入库，并比较全部报告和任务的内容摘要。实际结果在完成后补记，未执行的步骤不得提前称为通过。
